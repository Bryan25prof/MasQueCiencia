MQC — PENDIENTE A: Actualización de "Acerca de la Plataforma"
==================================================================

Qué es este paquete
--------------------
Es la actualización de contenido y presentación de la pantalla
"Acerca de la Plataforma" que pediste: corrige que Física ya está
disponible (ya no se presenta como "próxima fase"), agrega
transparencia sobre el uso de IA (ChatGPT/OpenAI y Claude/Anthropic),
reconocimiento de fuentes académicas (MEP, Didáctica Multimedia,
Editorial Porras, bibliografía universitaria), una declaración de
acceso gratuito, una explicación de datos/perfiles/Analytics/Supabase,
y un cierre de "Principios del proyecto" — todo organizado en 7 cards
cortas y visualmente jerarquizadas (nada de pared de texto ni pantalla
de términos y condiciones), manteniendo el lenguaje visual "Cosmos de
Laboratorio" de siempre.

Este paquete NO toca Storage, XP, progreso, exámenes, desbloqueos,
Suficiencia, PNE, Analytics, Supabase, perfiles ni rutas académicas —
es exclusivamente contenido/presentación de esa pantalla, tal como
pediste. Se probó con Playwright contra los archivos reales (28
verificaciones automatizadas, ver
MQC_PENDIENTE_A_IMPLEMENTACION_REPORTE.md para el detalle completo),
incluyendo una verificación específica de que el botón "♡ Apoyar MQC"
(inyectado por support.js) y el disparador oculto del panel de
desarrollador (devtools.js, 5 toques sobre el logo) siguen funcionando
exactamente igual que antes.

Archivos incluidos (3 en total), con su ruta EXACTA dentro del repo:

    index.html          ← REEMPLAZA (solo un comentario actualizado, sin cambios funcionales)
    js/core/router.js   ← REEMPLAZA

Cómo subirlo a GitHub
----------------------
1. Descomprimí este .zip en cualquier carpeta temporal. Vas a ver una
   carpeta "MasQueCiencia_Beta_v1.0/" con la misma estructura de
   subcarpetas que tu repo.

2. Copiá estos 3 archivos a las mismas rutas dentro de tu copia local
   del repo, reemplazando los que ya existen.

3. Confirmá los cambios con git y subilos a GitHub, por ejemplo:

     git add index.html js/core/router.js css/main.css
     git commit -m "Pendiente A: actualizacion integral de Acerca de la Plataforma"
     git push

desarrollador (5 toques sobre el logo) siguen apareciendo exactamente
