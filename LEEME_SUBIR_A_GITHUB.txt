MQC — FASE 2, LOTE 6: "Bandeja de excepciones de colegios"
=============================================================

Qué es este paquete
--------------------
Todo el código modificado del Lote 6 (la pestaña "Gestión de Colegios"
del panel de Analytics ahora separa los nombres legacy en "resueltos
automáticamente" / "requieren tu criterio" / "ya confirmados, ocultos",
en vez de listarlos todos por igual).

Este paquete NO requiere ninguna acción en Supabase. Es un refactor
100% de JavaScript de cliente — reutiliza la tabla school_alias_map
que ya existía desde el hotfix de catálogo de colegios.

Archivos incluidos (2), con su ruta EXACTA dentro del repo:

    js/data/catalogo-colegios.js
    analytics/analytics-admin.js

Cómo subirlo a GitHub
----------------------
1. Descomprimí este .zip en cualquier carpeta temporal. Vas a ver una
   carpeta "MasQueCiencia_Beta_v1.0/" con la misma estructura de
   subcarpetas que tu repo.

2. Copiá esos 2 archivos a las mismas rutas dentro de tu copia local
   del repo, REEMPLAZANDO los que ya existen con ese nombre.

3. Confirmá los cambios con git y subilos a GitHub, por ejemplo:

     git add js/data/catalogo-colegios.js
     git add analytics/analytics-admin.js
     git commit -m "Fase 2 Lote 6: bandeja de excepciones de colegios"
     git push

Qué NO hay que hacer
----------------------
- NO hay ningún archivo .sql en este lote — no hay que tocar Supabase
  para nada.

Cualquier duda, todo el detalle técnico y de verificación está en
MQC_AUDITORIA_FASE2_LOTE6_BANDEJA_COLEGIOS.md, que te llega junto con
este paquete.
